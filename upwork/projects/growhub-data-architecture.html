In Short

The problem

Sales were in Shopify, logistics and complaints in hand-typed Excel sheets, and web traffic in GA4. Every report was stitched together by hand, and different sheets gave different answers.

What I built

An automated platform that brings all of it into one warehouse every hour, checks the spreadsheet data for mistakes, and feeds more than ten Looker Studio dashboards.

The result

Reports that build themselves, one set of numbers for every team, and money that was quietly being lost, now found. All for about $30 a month.

What It Uncovered

Once the data finally met in one place, problems that no single system could show became obvious. growhub.ae delivers with its own drivers, who bring returned items back to the warehouse. Logistics logged those returns in Excel, but Shopify's stock count was often never updated:

Example: one product, two different stock counts

Shopify4 in stockmissing the return

Shelf5 in stockreturn logged in Excel

Across many products, gaps like this make items look closer to selling out than they are, and stock gets reordered too early. Unmatched returns are now flagged automatically, which cut stock discrepancies by 30%. The same check found $5K in refunds that had been paid out with no return ever logged.

How It Works

A layered design on Google Cloud. Each layer has one job, and data only flows downwards:

Key Decisions

Custom extractor, not a paid connector

No monthly licence for a small business, and full control over what is pulled from Shopify.

Trade-off: maintained in-house when the API changes.

ELT: load raw, model in dbt

All business logic is SQL in one place, so a changed rule rebuilds history in minutes.

Trade-off: raw data stays messy, so nobody reports from it directly.

Incremental, idempotent loads

Only changed records are pulled and MERGEd on their key, so any run can be repeated safely.

Serverless, hourly, deployed from Git

A Cloud Run Job on a schedule, redeployed by Cloud Build on every commit. No servers to maintain.

Trade-off: data can be up to an hour old, fine for daily decisions.

Making the Sources Agree

  • Cash on delivery. Drivers' collections are typed as free text such as "117+118+65". SQL parses them and matches them to orders, giving the true amount paid.
  • GA4 and Shopify. With no shared ID, sessions and orders are matched by day and campaign, giving conversion rate and revenue by channel.
  • Complaints. Complaints that mention several orders are split and linked back, so every order carries a complaint flag.
  • Spreadsheet governance. Locked templates, drop-down validation and named owners at entry, then automatic checks on every load. Rows that fail go to an exceptions report for the owner to fix.

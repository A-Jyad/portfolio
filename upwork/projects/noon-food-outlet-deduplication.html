One restaurant, one record: a clean outlet map for noon Food from three messy platforms

noon Food scraped every restaurant outlet listed on Talabat, Zomato and Careem, but the same restaurant appeared again and again under different names and pins. I built the matching algorithm that turned those listings into one clean database of every outlet in the city.

In Short

The problem

Most restaurants list on several platforms, and scraped data is messy. Names, spellings and map pins never match exactly, so no simple lookup could tell which listings were the same outlet.

What I built

A matching algorithm that treats two listings as the same outlet only when their names are similar and their locations are close, then merges each group into a single record.

The result

One record per real outlet, with everything each platform knew about it, and a map of the whole city's restaurant market, including which platforms every outlet was already on.

The Key Insight

Neither signal works on its own. Names alone would merge every branch of a chain; locations alone would merge every restaurant in a food court. Only when both agree is it the same outlet:

How It Works

Key Decisions

Location first, names second

Only listings near each other are compared. That skips almost every impossible pair across the city and keeps chain branches apart.

Trade-off: an outlet pinned badly on one platform can be missed.

Fuzzy, not exact, names

Fuzzy matching tolerates typos, reordered words and extras like "Restaurant", which exact matching never could.

Trade-off: thresholds need tuning so similar names don't over-merge.

Group matches, don't just pair them

Linked matches become one group, so an outlet on three platforms, or listed twice on one, collapses into a single record.

Trade-off: one bad link can join two groups, so match rules stay strict.

Keep every source's data

The merged record combines what each platform knew and notes where the outlet is listed, instead of picking one source.

Trade-off: conflicting values need a rule for which source wins.
